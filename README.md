# files/

Put the PDFs you want to link to from a QR code in this folder.

**Naming rule:** lowercase letters, numbers, and hyphens only, no spaces — e.g. `my-resume.pdf`, `dinner-menu.pdf`. The generator on the site suggests this exact format automatically when you choose a file.

**After adding a PDF here:**
1. Commit the change to your `main` branch.
2. Wait about a minute for GitHub Pages to redeploy.
3. The file will be live at:
   `https://<your-username>.github.io/<your-repo>/files/<filename>.pdf`
4. Paste that exact URL into the generator's "Public URL" field and generate the QR code.

This folder starts empty except for this note — GitHub doesn't track empty folders, so this file also keeps `files/` present in the repository until you add your first PDF.

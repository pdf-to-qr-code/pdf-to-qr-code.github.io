Generate a QR code How storage works

A QR code cannot normally contain a full PDF because QR codes have limited data capacity. Instead, this tool creates a QR code containing a public URL that points directly to your PDF.

When you click Upload PDF & Generate QR, your browser sends the PDF to the Render backend. The backend uploads the PDF into the GitHub PDF storage repository, then returns the public GitHub Pages URL.

The QR code is generated from that real public URL. When someone scans it, their browser opens the PDF directly.

Where your PDF is stored

Your uploaded PDFs are stored in your GitHub repository and served publicly through GitHub Pages.

  1. GitHub repository

    The backend uploads files to:
    bazpurss223/pdf-storage

  2. PDF folder

    Each uploaded PDF is placed inside:
    files/

  3. Unique filename

    The backend adds a random prefix to prevent filename collisions. For example:
    973cf255ed2c825b-Motorcycle-Bikers-png-svg.pdf

  4. Public URL

    The backend returns a URL like:
    https://bazpurss223.github.io/pdf-storage/files/filename.pdf

  5. QR code

    The QR code contains that exact public URL. Scanning it opens the PDF hosted by GitHub Pages.

Frequently asked questions

Can a QR code contain an entire PDF? +
Usually no. QR codes have limited data capacity, so normal PDFs are much too large. This tool puts the public PDF URL inside the QR code instead.
Does this tool upload my PDF? +
Yes. When you click "Upload PDF & Generate QR", your PDF is sent to the Render backend. Render then uploads the PDF to the configured GitHub repository.
Where is my PDF stored? +
The PDF is stored in the GitHub repository bazpurss223/pdf-storage inside the files folder. GitHub Pages then serves the file publicly.
Why could my PDF URL show 404? +
A 404 normally means the PDF was not successfully committed to the GitHub repository, GitHub Pages is not configured correctly, or Pages has not finished deploying the latest commit.
Why does the backend need a GitHub token? +
The Render backend uses the GitHub API to create the PDF file inside your repository. The token must stay on Render and must never be placed in this website's JavaScript.
Will scanning the QR open the PDF? +
Yes, once GitHub Pages has deployed the uploaded file, the QR code points directly to that PDF URL.
